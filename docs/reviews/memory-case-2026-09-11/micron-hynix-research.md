# 美光 / SK 海力士一手资料研究备忘录

研究截止：2026-09-11。用途：支持存储行业投资判断与 research/profile 产品评测。金额分别使用美元 billion（十亿美元）及韩元 trillion（万亿韩元），不使用未经核验的实时汇率进行比较。事实、管理层预测、研究判断分列；没有取得可验证行情，故不提供伪精确的当前 PE 或上涨空间。

## 投资结论

两家公司都值得列入核心研究名单。海力士的看点是 HBM 量产经验、先进封装与客户共同开发；美光的看点是 HBM4、服务器 DRAM、数据中心 SSD 的组合以及已披露具体价格结构的多年供应合同。选择哪家公司更值得买，最终要比较**正常化经营现金流对应的价格**，不能比较当季净利增速。

当前证据对“只是 HBM 单一产品热潮”构成反证：美光非 HBM 终端同样大幅涨价；但对“周期已经消失”也构成反证：美光收入增长明显来自价格，而非同等幅度的销量增长。应同时建模结构性盈利台阶与供需逆转。

## 2. 美光的合同质量与公司深度

管理层在 6 月 24 日说明签订 16 份战略客户协议。14 份合同按最低价格与数量对应剩余收入约 100；其中包含季后协议，**季末 RPO 仅超过 5**。协议具有 take-or-pay 数量约束；多数定价为固定价或上下限，但部分仍随市场。所有目标协议签订后，固定价或接近 CQ2 现价上限的协议预计约占总收入 40%。价格底线尚未量化公开，不能自行填入模型。

已签协议相关押金及财务承诺预计 22，其中现金押金约 18；押金记入**融资现金流**，未来合约后半段返还，不增加 FCF。持有这部分现金并不等于新增可分配利润。披露还指出更复杂的未来产品及新工厂将推高混合 DRAM 单位成本，不能假定价格有下限就意味着毛利永久固定。[Q3 prepared remarks，第 2、3、7 页](https://s25.q4cdn.com/621799436/files/doc_financials/2026/q3/Q3-FY26-Prepared-Remarks.pdf)

技术证据：公司 2026-03-16 宣布 Vera Rubin 用 36GB 12H HBM4 已量产出货；同时推出 SOCAMM2 与 Gen6 SSD。官方规格中的功耗及带宽优越性多数基于内部测试、特定容量与工作负载，应视作产品认证和差异化线索，不能把厂商不同测试条件下的数字直接排行。[公司发布，2026-03-16](https://www.globenewswire.com/news-release/2026/03/16/3256773/0/en/Micron-in-High-Volume-Production-of-HBM4-Designed-for-NVIDIA-Vera-Rubin-PCIe-Gen6-SSD-and-SOCAMM2.html)

产能需按“投产→良率→客户认证→出货”追踪，开工不等于供给。最新中长期计划在 7 月 9 日提高至 2035 年前美国投资超过 250；该数字跨多年且涵盖技术投资，不是 2027 单年资本开支。[公司最新美国投资公告](https://www.globenewswire.com/news-release/2026/07/09/3324807/0/en/Micron-Accelerates-U-S-Investments-Pours-First-Concrete-at-New-York-Fab.html)

## 5. 估值模型建议：透明参数，而非当季 PE 外推

推荐先对业务价值建模，再调整金融投资与现金债务：

`正常化收入 = Σ(产品位元出货 × ASP)`

`正常化经营利润 = 收入 × 正常化营业利润率`

`FCFF = 经营利润 × (1−正常税率) + 折旧摊销 − 毛资本开支 + 可持续补贴 − 营运资本增加`

`股权价值 = 经营业务价值 + 非经营投资税后价值 + 可自由使用现金 − 债务 − 客户押金等偿付义务`

随后除以实际稀释普通股数；ADS 还需换算。海力士的金融投资价值若在资产端加入，相关估值收益与股息就不能再次作为经营盈利资本化。美光客户返还押金若只加入现金而不计偿付义务，同样高估股权价值。

下列仅为**分析者压力测试假设**，不是公司指引、市场一致预期或目标价。适合在 profile 中用滑杆观察，不应将表格中点直接变成买入价。

| 参数 | 悲观 | 中性 | 乐观 |
|---|---:|---:|---:|
| 未来 12–24 个月收入 / 最近已公布季度年化收入 | 0.60× | 0.90× | 1.20× |
| 正常化营业利润率 | 35% | 55% | 70% |
| 正常化税率 | 25% | 22% | 18% |
| 正常化经营利润估值倍数 EV/EBIT | 8× | 11× | 14× |
| 决策关注 | ASP 大降、竞争与客户压价 | 部分超额盈利保留 | 长协兑现、需求持续超供给 |

以上让两家公司在相同假设下可比较，同时应给予不同产品结构不同 ASP 曲线。不能把全公司收入都当 HBM，也不能在 HBM 收入之外再完整叠加 DRAM 总收入。乐观情景同样保留盈利率回落，因为最新超高利润率尚不足以证明长期稳态。

合理买入条件应为：按所选价格计算的中性正常化回报达到收益要求，悲观情景的损失可承受，并且长期合同、资本开支及客户现金支付证据支持模型。若只能获得当季净利润与新闻，结论应是“观察名单/等待估值验证”，而不是低 PE 直接买入。

## 6. 必须持续挑战的反证

| 初始观点 | 最重要的反证或监测指标 |
|---|---|
| HBM 壁垒让周期消失 | 客户多源认证、相同平台订单份额变化、降价要求、HBM 产能转为传统 DRAM |
| 长协锁定多年利润 | 最低采购量、价格底线、成本通胀分担、履约/信用风险、合同续约价格 |
| AI 推理永远增加需求 | 实际收费收入与现金回收、单位 token 存储量、压缩/量化/缓存分层、服务器内存配置调整 |
| 厂商盈利高就会高回报股东 | 毛资本开支、施工和良率延误、每位元成本、每股 FCF、增发稀释 |
| 当前现金非常充裕 | 客户押金、投资变现与税款、可出售证券流动性、未来不可撤销采购承诺 |
| NAND 与 HBM 是同一个投资逻辑 | NAND 多家供给与层数升级、企业 SSD 认证及控制器价值、HDD/SSD 总拥有成本边界 |

## 7. 这次案例应成为 research/profile 的验收标准

1. 时间完整：每个数字带公布日、财期起止、as-of、GAAP/K-IFRS、金额单位；新季度指引与实际不混淆，53 周财年可见。
2. 证据可追溯：财报表格行/页能点击；正文失败、镜像、厂商测试、管理层展望分别标记，不用检索摘要伪装已核验事实。
3. 正常化必做：海力士净利润桥接到经营利润；美光 CFO 桥接到毛/净 capex、adjusted FCF；投资股息及客户押金有分类。
4. 证券实体更新：SKHY ADS、新上市股数、普通股换算；供应链公司、资产组合、不同上市实体不可混为一谈。
5. 可视化至少包括：ASP×位元出货驱动树、HBM/传统 DRAM/NAND 收入结构、利润与现金流桥接、产能投放时间轴、双变量估值敏感度、反证监控表。
6. 深度应覆盖未披露部分：未取得 HBM 独立毛利、真实良率或特定客户份额时，显示未知；不能用总公司指标或厂商宣传自动填补。
