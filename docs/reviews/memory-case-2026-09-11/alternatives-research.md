# 存储案例：闪迪、铠侠、三星与替代投资机会

研究截止：2026-09-11（Asia/Shanghai）。独立一手资料 memo，供主报告整合。所有下列引用均经 web 打开官方公告、IR PDF 或 SEC 附件；预期与已实现业绩分开。不提供未经核验的当日价格、市场市值、实时估值或目标价。

## 1. 可直接用于结论的判断

**候选池应覆盖不同利润来源，不能将“存储”当成单一投资品。** 美光、海力士的 HBM/DRAM 逻辑，与闪迪、铠侠的 NAND/企业 SSD，和 WDC、Seagate 的大容量 HDD 不同。设备公司 Lam Research 则将竞争者扩产支出变成自己的收入。这些公司仍共同暴露于 AI 资本开支周期，并不天然构成有效分散。

在尚未取得同一交易日价格和中周期估值之前，不能负责任地宣布某公司现在“最值得买”。我的条件性优先级为：

| 投资判断 | 优先进一步研究 | 必须验证的条件 | 可以推翻判断的证据 |
| --- | --- | --- | --- |
| 看好 HBM/高端 DRAM 持续稀缺 | MU、SK hynix | 客户认证、良率、下一代产品份额和扩产后的 ROIC | 供给超预期、客户议价回升、技术份额流失 |
| 看好 NAND 从短周期销售转向有保障的长期合同 | SNDK | NBM 地板价、真实履约保障、扣预收款后的 FCF 与产能义务 | 合同被重谈、预收款消耗过快、产能兑现与售价错配 |
| 认为 NAND 价格上涨已接近利润高点，仍看好数据存储量 | WDC；其次比较 STX | 经常性 FCF、每 TB 成本、客户合同和增长所需资本；比较两者同日 EV | 客户去库存、定价回落、HDD 被 SSD 在更多层级替代 |
| 看好 HAMR 技术带来的密度与成本优势 | STX | 客户认证、产量、良率、毛利兑现；愿意承担其剩余净债务 | 新平台退货/可靠性问题、切换成本上升、认证推迟 |
| 认为厂商竞相扩产比存储售价更可持续 | LRCX | 存储设备订单与收入转化、服务收入、合理估值 | 客户削减资本开支、出口约束、新机台验收推迟 |
| 看好三星 HBM/Foundry 执行改善及折价修复 | Samsung | 必须做分部估值，证实股价对现金及非存储业务估值的折价 | 高资本消耗业务抵消存储回报、追赶投入长期压低集团 ROIC |
| 寻找日股 NAND 相对价值 | Kioxia 285A | 与 SNDK 统一租赁/JV/股数/币种后，确有估值折价 | 表面低 PE 仅由周期峰值或拆股口径造成 |

这里 WDC/STX/LRCX 是**可替代的利润来源**，并非已经证明的更低风险或更高预期收益标的。

## 2. 身份与业务边界

Sandisk 于 2025-02-21 完成 Flash 业务分离，2025-02-24 开始以 SNDK 交易；WDC 保留 HDD。品牌名不能识别上市公司经济归属：带 WD/WD_BLACK 品牌的 SSD 仍可能属于 Sandisk。历史 WDC 的收入、利润、估值不能直接和拆分后继续经营口径拼接。[SEC 分离协议及 8-K，2025-02-21](https://www.sec.gov/Archives/edgar/data/2023554/000119312525033433/d849281d8k.htm)、[SEC 上市新闻稿，2025-02-24](https://www.sec.gov/Archives/edgar/data/2023554/000119312525033433/d849281dex991.htm)、[官方品牌 FAQ](https://www.sandisk.com/sandisk-separation-faqs)。

对项目 profile 的检验：SNDK 不应显示为 WDC 子公司；WDC 不应继续直接享受 NAND 或 SSD 增长叙事；公司、业务、产品品牌、历史公司行动必须分层建模。

## 3. 财务证据卡

### Sandisk：最新增长很强，但现金流和利润必须还原

FY2026 Q4 截至 2026-07-03，公告 2026-08-05；金额为 USD billion。

| 指标 | 数值 |
| --- | ---: |
| 季度收入 / FY26 收入 | 8.965 / 20.248 |
| 季度 GAAP / Non-GAAP EPS | 43.97 / 39.25 美元 |
| 季度 CFO / 报告 FCF / adjusted FCF | 7.126 / 7.083 / 5.035 |
| FCF 调整：JV 现金流 / NBM 预付款和保证金 | -0.110 / -1.938 |
| 年末现金 / 长短期债务 | 4.762 / 0 |
| 季度权益投资净收益 | 0.804 |

公司定义 adjusted FCF 会扣除 NBM 预收款并计入 Flash Ventures 现金流。因此不能把 7.083 的 FCF 全部视为本期可持续经营创造的现金，也不能把 43.97 的 EPS 全部视为存储经营盈利。[Sandisk 财报及调节表，2026-08-05](https://www.sandisk.com/company/newsroom/press-releases/2026/2026-08-05-sandisk-reports-fiscal-fourth-quarter-2026-financial-results)。

补充经营证据：Q4 non-GAAP 毛利率 84.6%；收入环比增长约三分之一来自量、三分之二来自价格。Datacenter 收入 2.977，占总收入约 33.2%（自行计算）；公司所报 Datacenter 位元占比为 38%，两者不能混用。Q4 自有 PP&E 支出仅 0.043，但连同 JV 后的 cash capex 为 0.153、gross capex 为 0.562。8 家客户 NBM 合同地板收入 93.9，季度末 RPO 59.8（含期后合同 91.1），平均期限超过 4 年；这些是合同/管理层披露，不是当期确认收入。[Q4 投资者演示第 5—14 页，2026-08-05](https://investor.sandisk.com/static-files/c75d1bee-c5c9-4e5a-8605-302c1aeac59b)。

分析：竞争优势已经超出消费品牌，应研究企业 SSD 客户认证、控制器/固件、BiCS 迁移和 JV 成本；投资关键是高利润能否跨周期保留。NBM 可能降低价格与需求风险，但需要阅读取消权、地板/天花板、客户信用、保函性质和供货义务，不能把 RPO 等同无风险资产。零金融债务也不等于零经济义务：预收款对应未来供货，JV 对应投资承诺。

### Kioxia：财务去杠杆明显，仍必须计入租赁、汇率与法律成本

截至 2026-06-30 的三个月，发布 2026-07-31；JPY billion。

| 指标 | 数值 |
| --- | ---: |
| 收入 / IFRS 经营利润 | 1,767.117 / 1,270.017 |
| CFO / PP&E 购置 | 866.337 / 51.176 |
| 现金 / 债券与借款 | 791.014 / 634.554 |
| 租赁负债 | 203.277 |
| SSD & Storage 收入 | 1,174.719 |
| 诉讼损失拨备费用 | 36.6 |

自行计算：不含租赁净现金 156.460；计租赁则净债务 46.817。简式 CFO−PP&E 为 815.161，不能冒充公司定义的完整 FCF。SSD & Storage 同时含 PC、数据中心和企业，不能冒充纯数据中心收入。报表 EPS 尚未反映 2026-10-01 生效的 1 拆 3，估值必须统一股数。原始报表为百万日元，以上转换为十亿日元。[官方 IR 链接的东京交易所季度财报，第 0、5、10、14、15 页，2026-07-31](https://ssl4.eir-parts.net/doc/285A/tdnet/2859908/00.pdf)。

分析：铠侠是 SNDK 重要相对价值比较对象，但不是一份没有差异的替代证券。共同 JV 令制造技术和供给高度相关；销售组合、融资结构、汇率、资本开支承担和治理不同。价格上涨时收入与利润同时急升，不应机械套用个位数“峰值 PE”证明便宜。法律拨备既不能遗漏，也不能直接当成每年固定费用；应对和解现金支出作单独情景。

### 共同供给风险：扩产已进入可核验的项目层面

2026-08-27，Kioxia/Sandisk 宣布计划至 2032 年在日本投资超过 310 亿美元（约 5 万亿日元），以政府支持为条件，涵盖四日市、北上设施与技术。**这是两家合计、跨多年、有条件的投资计划；既不是各花 310 亿美元，也不是当年 capex。** [联合公告，2026-08-27](https://www.sandisk.com/company/newsroom/press-releases/2026/2026-08-27-kioxia-and-sandisk-to-invest-over-31-billion-in-japan-extending-leadership-in-memory-industry)。

分析：扩产能扩大长期位元供给并降低成本，却也可能侵蚀未来稀缺溢价。行业研究应逐工厂追踪开工→设备搬入→良率爬坡→有效位元产出，不能仅将每家公司“AI 需求旺盛”的表态叠加成需求预测。SNDK 与铠侠的 JV 资本开支不可在行业供给图中重复计算。

### Samsung：必须用集团分部估值，不可把 DS 当成纯 Memory

2026 Q2 截至 2026-06-30，发布 2026-07-30；KRW trillion。集团收入 171.5、经营利润 89.5；DS 收入 127.5、经营利润 89.2。DS 包括存储、System LSI 和 Foundry，财报没有据此单独给出纯 Memory 利润。公司表示 H2 服务器 DRAM/eSSD/HBM 需求强，计划聚焦 HBM4、DDR5、SOCAMM2，且已寄出 HBM4E 样品。这些产品进度不能等同全部客户认证或收入兑现。[三星官方 Q2 公告，2026-07-30](https://news.samsung.com/global/samsung-electronics-announces-second-quarter-2026-results)。

集团 CFO 105.08、PP&E 购置 14.11，现金类资产 190.00，净现金 167.59。自行计算简式 CFO−PP&E 为 90.97；它是集团当期口径，不是纯存储自由现金流，不宜将其直接归入 Memory DCF。[Q2 演示附录现金流，第 14 页，2026-07-30](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_2Q_conference_eng.pdf)。

分析：三星提供财务韧性和执行改善的选择权，同时混入手机、显示、晶圆代工等业务。评价其是否胜过海力士，应对 Memory 用中周期利润，对其他业务独立估值，再加净现金、扣资本消耗或控股折价；不能直接比较集团收入增速或集团 PE。当前资料未核实 HBM 客户逐一认证、市场份额、各分部现金流，结论应明确条件。

### WDC：应以 HDD 经常性现金流估值

FY2026 Q4 截至 2026-07-03；2026-08-05 公告，USD billion。Q4 收入 3.747，GAAP 毛利率 54.1%，CFO 1.389、FCF 1.281；FY26 收入 12.919、FCF 3.511。期末现金 1.579、金融债务 1.052。GAAP EPS 8.21 对比 non-GAAP 3.56；本季残留 SNDK 权益收益 2.050，年末残留投资账面值为零。不能以包含处置/重估收益的 GAAP EPS 算持续经营 PE。[WDC Q4 财报及附表，2026-08-05](https://investor.wdc.com/news-releases/news-release-details/wd-reports-fiscal-fourth-quarter-and-fiscal-year-2026-financial)。

分析：这是对大容量存储经济性的暴露。其吸引力取决于每 TB 成本与售价的差、单位磁盘容量增长、产品切换资本需求，以及长期订单能否转换为现金。相对 STX 的选择应该由技术路线执行、净债务、经常性现金流和同日 EV 决定。若 WDC 股价隐含较低中周期 FCF 倍数，且新增容量不需大幅扩充工厂，可能比高估值 NAND 高弹性标的更适合风险调整后的配置；目前未核实同日价格，不能断言折价存在。

### Seagate：HAMR 技术路线与剩余债务必须一起看

FY2026 Q4 截至 2026-07-03。Q4 收入 3.629、GAAP 毛利率 52.3%、non-GAAP EPS 5.71；FY26 收入 12.195、FCF 约 3.1，年末债务约 3.6、现金约 1.7（USD billion）。公司指引 FY27 Q1 收入 4.1±0.1、non-GAAP EPS 7.30±0.20。来源日期有小差异：8-K 事件日和官网标 2026-07-28，SEC 新闻稿附件正文标 07-29，应保留该差异。[SEC Q4 附件](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000153/stxq42026pressreleasefinan.htm)、[SEC 8-K](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000153/stx-20260728.htm)。

2026-03-03，公司宣布 Mozaic 4+ HAMR、最高 44TB 已获两家大型云客户认证并量产；未来 100TB 是路线目标，不是已交付事实。[Seagate 技术公告，2026-03-03](https://investors.seagate.com/news/news-details/2026/Seagate-Delivers-Industrys-Highest-Capacity-Hard-Drives-with-Next-Generation-Mozaic-4/default.aspx)。

分析：HAMR 带来的密度和 TB 成本改善可以形成超越行业销量周期的增量利润，但需要跟踪实际产品组合、良率、返修率及客户采纳。高容量旗舰规格本身不足以推出利润率持续提升。STX 的剩余净债务意味着同样的需求下滑对股权价值可能更敏感；不能仅用 EPS 高于 WDC 判定其更便宜。

### Lam Research：扩产与技术复杂度的替代受益者

截至 2026-06-28 季度，2026-07-29 发布。收入 6.722（USD billion），GAAP 毛利率 51.7%、EPS 1.81；客户支持相关收入 2.472，其中含服务、备件、升级及非领先制程设备，因此并非全部经常性订阅收入。中国地区收入占比 26%。[Lam 季度财报，2026-07-29](https://investor.lamresearch.com/image/Jun_Q_2026_Earnings_PR.pdf)。

当季系统收入的存储占比 46%，其中 NVM 23%、DRAM 23%；这些比例不可用作集团全部收入的存储占比。公司披露 NAND 收入环比翻倍，并预计 CY26 WFE 支出处于 1,500 亿美元低端区间，后者是管理层预期。[Lam 投资者演示，第 3、11 页，2026-07-29](https://investor.lamresearch.com/image/Q4_2026_slides_final.pdf)。

分析：若厂商的定价红利吸引持续投资，刻蚀、沉积及升级设备可以先于新增存储供给获得收入；此时 LRCX 是比单押一个存储厂商更值得研究的替代方向。但其订单同样会随资本开支反转，且存在地区与政策集中度。应估值正常化设备收入和支持业务，不能把订单高点乘以成长股高倍数。其他设备公司需要另做公司级核验后才能列入买入名单。

## 4. 应交付的专业模型，而不是只交付公司故事

1. **分业务经济模型**：DRAM/HBM 用位元、产品组合、良率、晶圆及封装约束；NAND 用位元×ASP、节点迁移成本、企业 SSD 渗透、JV 与合同义务；HDD 用出货 EB、每台 TB、每 TB ASP、BOM 与密度迁移；设备用晶圆厂投资、设备份额、验收和服务收入。
2. **统一财务桥**：GAAP/IFRS→经常性经营利润→税后经营利润→营运资本→维护/增长 capex→可分配现金。单列 JV、租赁、补贴、客户预付款、诉讼、股权重估、SBC、回购与可转债稀释。
3. **中周期估值**：用至少完整一轮景气数据估计正常化利润率及 FCF。保留公司当期财报、管理层指引、第三方一致预期、研究者假设四类标记。情景值不能伪装成一致预期。
4. **可执行决策**：先获得同日价格、股数、FX，再计算统一 EV/正常化 FCF、EV/EBIT、P/B 与 ROIC。示例决策公式为“可接受 EV = 研究者假设的中周期 FCF ÷ 要求现金收益率”；股权价值再加可分配净现金并扣未反映义务。要求收益率是投资假设，不能将任意门槛写成市场事实。
5. **反证与观察清单**：每一条看多论点需要一个会令其失败的指标、阈值和下次复核日期。资本开支、客户预付款、ASP、应收增速、产能与认证应同时可见。

## 6. 目前仍缺少、必须披露的证据

尚未核实 2026-09-10 美股收盘/09-11 亚洲交易时点的可比股价、市值、实际稀释股数、统一 FX、期权隐含预期及卖方一致预期。本 memo 因此不支持精准目标价、当日买入价或绝对收益排名。还需核实 NBM 完整条款、各家客户集中度与客户库存、HBM 逐客户认证、各厂实际良率、设备订单取消权及全周期资本效率。

上述缺口影响**投资建议的价格和仓位**，不妨碍先完成业务判断、财务纠偏和候选池筛选。主报告应把“业务值得研究”“价格具有安全边际”“现在应买入”三个层级明确区分。
