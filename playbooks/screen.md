# F3 粗调研 + 筛选 playbook（screen）

任务：对标的池每票产出粗调研卡，给出推荐深研名单与淘汰理由，呈交人工闸口。

## 粗调研卡字段（每票）
- 业务一句话（有证据）
- 赛道归属证据 id
- 关键指标：市值 / 收入（TTM 或 FY）/ 现金 / 增速（查不到就标「未知」）
- 初步亮点、初步风险（各 1-2 条，带证据）
- 信息丰富度评级：A（上市多年覆盖广）/ B（适中）/ C（冷门新上市）——
  C 级票的推算数字必须标「低置信」
- 推荐/不推荐 + 一句话理由

## 筛选纪律
- 推荐深研名单 ≤ 6 只（深研成本高，宁精勿滥）；
- **被淘汰的票必须留淘汰理由**（证据或「数据不足」），不许黑箱漏票；
- 判断依据必须可回溯：结论引用证据 id；
- 这是「粗筛」不是「终局」——目标是找出值得烧大钱深研的，不是现在就定论。

## 闸口交互
- 呈交：筛分表 + 推荐名单 + 淘汰理由；
- 被打回时：读反馈，按反馈扩池/补调研/换维度，产出「本轮改了什么」diff 重呈。
