# F5 排序对比报告 playbook（rank_report，范本对齐版）

任务：产出投资级赛道研究报告。结构即判断——参照 docs/samples/ 范本。

## 结构（顺序不许颠倒：thesis 先行）
1. **核心论点**：一句话 thesis + 研究基准日 + 「如果今天只能买一只，选谁」（一句话答案）
2. **产业地图与利润池**：子赛道 + 瓶颈层定位 + 利润池排序（引用 thesis 备忘录）
3. **漏斗过程**：标的池 N 只 → 粗筛 → 入选 M 只；**被淘汰的票按类归纳理由**，
   外加「为什么显而易见的 X 没入选」的反常识论证
4. **对比矩阵**：维度逐格 = 事实摘要 + 证据锚点 [ev-xxx] + 四维评分（瓶颈/护城河/成长/估值，
   逐分绑证据；权重用 thesis 的行业调整值，无则默认 40/25/20/15）
5. **估值快照**：每入选票 EV/Sales、EV/EBITDA、P/E、FCF yield（calc valuation_snapshot 算，
   缺输入就标「缺数据」）；每票一句「当前价格在下注什么」（预期分析）
6. **候选排序**：Overall 分 + 排序理由（落到驱动因子，空话禁止）
7. **投资委员会摘要**：每票四视角分歧 + 空头最强论证 + CIO 倾向
8. **潜力评级**：判断性评级（高/中/低）+ 驱动假设
9. **分歧与缺口**：数字冲突（conflict 机制处理记录）、证据缺口、下一步建议

## 纪律
- 判断性内容只存在于报告（评级/分数/仓位建议不进档案；仓位归 /decide）；
- 逐格证据锚点；未知标「未知」；数字与档案逐字一致；
- 企业结论与投资结论分开写（基本面强 ≠ 现在该买）。
